# 画面設計書: グラフ解析モード

## 画面概要

コード構造を4種類のグラフで可視化する。

## グラフ種別

| 種別 | 説明 | 状態 |
|------|------|------|
| コールツリー | 関数の呼び出し関係を列ベース階層で表示 | 実装済み |
| データフロー | 変数の定義→使用の流れ | 実装済み |
| フローチャート | 関数ごとのJIS準拠制御フロー図 | 実装済み |
| クラス図 | UML風のクラス属性・メソッド図 | 実装済み |

## ツールバー

| 要素 | 説明 |
|------|------|
| レイアウト | 階層/力学/円形/カマダ・カワイ (コールツリー用) |
| 表示 | 関数名 / コメント表示切替 (コールツリー用) |
| フィット | グラフ全体をビューに収める |
| エクスポート | カテゴリ分けプルダウン(19形式) + 保存ボタン |

## 絞り込みバー

| 要素 | 説明 |
|------|------|
| ファイル | フォルダ解析時、ファイルで関数を絞り込み |
| 関数 | 検索可能プルダウン (部分一致) |
| 範囲 | 呼び出し先のみ / 経路+呼び出し先 / 兄弟も含む / ルートから全部 |

## コールツリー仕様

- 列=階層 (左=浅い→右=深い)、行=ソース出現順
- 定義された関数のみ (組み込み除外)
- 階層ヘッダー + L字接続線 + 20色深さ別色分け
- 複数呼出: 別ノード展開 + (x2)バッジ + 太枠
- クロスファイル統合対応
- ツールチップにdocstring表示
- スクロール=上下移動、Ctrl+スクロール=ズーム

## フローチャート仕様

→ 詳細は [flowchart-spec.md](flowchart-spec.md) を参照

- JIS準拠図形 (角丸端子/四角処理/ひし形判断/台形ループ/平行四辺形入出力)
- 全ノード1列配置、ノード幅自動拡張
- YES=下、NO=右に分岐 (右60pxオフセット)
- 開始: 「開始: 関数シグネチャ」、終了: 「終了」
- クラスメソッドも対応 (ClassName.method_name)

## DFD仕様

→ 詳細は [dfd-spec.md](dfd-spec.md) を参照

- 変数の定義・使用・関数間受渡しを可視化
- プロセス経由のデータフロー (変数→変数の直接エッジなし)
- 関数内DFD + クロスファイル概要DFD
- 変数変更時の影響範囲をひと目で把握

## クラス図仕様

- UML風ボックス (クラス名/属性/メソッド)
- 属性: 名前、型、デフォルト値
- メソッド: 名前、引数(型+デフォルト)、戻り値型
- @property, @staticmethod 検出
- 継承矢印 (白三角)
- dataclass対応

## エクスポート (19形式)

| カテゴリ | 形式 |
|---------|------|
| 画像 | PNG, SVG, JPEG, PDF, BMP, WebP, TIFF, GIF, EPS |
| ビジネス | Excel, Visio |
| 開発者 | DOT, Mermaid, PlantUML, Draw.io |
| データ | JSON, XML, YAML |
| Web | HTML |

- 画像形式: GUIのQGraphicsScene描画をそのまま保存
- ファイル名: グラフ種別に応じて `flowchart_関数名.png` / `call_tree.png` 等
- DOT: フローチャート時はJIS図形shape属性付き
