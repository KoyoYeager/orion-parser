# 画面設計書: グラフ解析モード

## 画面概要

コールツリー・データフローを列ベース階層レイアウトで可視化。
関数にフォーカスしたサブツリー表示、19形式エクスポートに対応。

## ツールバー (1行目)

| 要素 | 説明 |
|------|------|
| レイアウト | 階層(dot) / 力学 / 円形 / カマダ・カワイ |
| 表示 | 関数名 / コメント(なければ関数名) |
| フィット | グラフ全体をビューに収める |
| エクスポート | カテゴリ分けプルダウン + 保存ボタン |

## 絞り込みバー (2行目)

| 要素 | 説明 |
|------|------|
| ファイル | フォルダ解析時、ファイルで関数一覧を絞り込み |
| 関数 | 検索可能プルダウン (入力で部分一致検索) |
| 範囲 | 呼び出し先のみ / 経路+呼び出し先 / 兄弟も含む / ルートから全部 |

## コールツリー仕様

### レイアウト
- 列 = 階層 (左=浅い、右=深い)
- 行 = ソース出現順 (上→下)
- 階層ヘッダー「階層1, 階層2...」を最上部に表示
- L字型接続線 (親の右端→横→縦→横→子の左端)
- ノード固定 (ドラッグ不可)

### ノード表示
- ラベル: 定義された関数名のみ (組み込み関数・メソッド呼び出しは除外)
- ツールチップ: マウスホバーでdocstringをポップアップ表示
- 表示モード切替: 関数名 or コメント (なければ関数名にフォールバック)

### 色分け
- 階層ベース: 20色パレット (depth 0=水色, 1=青, 2=緑, 3=黄, ...)
- 枠線: 2回呼出=橙太枠, 3+回呼出=赤太枠
- 複数呼出: 別ノードとして展開 + ラベルに(x2)バッジ

### クロスファイル統合
- フォルダ解析時、全ファイルの関数を統合したコールツリーを表示
- 各ノードにファイル情報を保持 (詳細パネルで確認可能)
- ファイル選択 → 関数プルダウンが連動して絞り込み

### フォーカスモード (4種)
| モード | 説明 |
|--------|------|
| 呼び出し先のみ | 選択関数から呼ばれるものだけ |
| 経路 + 呼び出し先 | ルートからの経路 + 呼び出し先 |
| 兄弟も含む | 同じ親から呼ばれている関数も表示 |
| ルートから全部 | 最上位からすべて表示 |

## エクスポート形式 (19種)

| カテゴリ | 形式 |
|---------|------|
| 画像ファイル | PNG, SVG, JPEG, PDF, BMP, WebP, TIFF, GIF, EPS |
| ビジネス向け | Excel (.xlsx), Visio (.vsdx) |
| 開発者向け | Graphviz DOT, Mermaid, PlantUML, Draw.io |
| データ形式 | JSON, XML, YAML |
| Web形式 | HTML (インタラクティブ) |
