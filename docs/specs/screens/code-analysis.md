# 画面設計書: コード解析モード

## 画面概要

ソースビューア(左) + 解析サブタブ(右) の2ペイン構成。
解析結果の項目をクリックするとソースの該当行・文字がハイライトされる。

## サブタブ

| タブ | 内容 |
|------|------|
| シンボル一覧 | 関数・クラス・変数・import をカテゴリ別テーブル表示 |
| トークン | 字句解析結果を色分けテーブル表示。クリックでソース文字ハイライト |
| AST | 構文解析結果をツリービュー + JSON詳細パネル |

## 双方向連動

- サブタブの行クリック → ソースの該当行にスクロール＆ハイライト
- トークンクリック → 行背景(黄) + 文字(オレンジ)の2重ハイライト
- ソースの行クリック → サブタブで対応項目を選択
