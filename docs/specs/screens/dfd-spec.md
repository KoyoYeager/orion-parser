# DFD (データフローダイアグラム) 仕様書

## 概要

変数の定義・使用・関数間の受け渡しを可視化する。
変数を変更した際の影響範囲をひと目で把握できることが目的。

## DFD要素

| 要素 | 形状 | 色 | 用途 |
|------|------|-----|------|
| 外部エンティティ | 四角 | 水色 `#B3D9FF` | 関数パラメータ、戻り値 |
| プロセス | 角丸四角 | 青 `#85C1E9` | 関数呼び出し (データを変換) |
| データストア | 平行四辺形 | 緑 `#A9DFBF` | 変数 (データの保管場所) |
| データフロー | 矢印 | — | 変数名をラベルに表示 |

## データフロー規則

- **データはプロセスを経由して流れる** — 変数→変数の直接エッジは原則なし
- **例外**: `y = x + 1` のような関数呼出を伴わない代入は直接エッジ
- **パラメータ → プロセス → 変数 → プロセス → 変数** のチェーンで表現

## 抽出する情報

### 関数内
| 情報 | 内容 |
|------|------|
| パラメータ | 関数の入力引数 |
| 変数の定義 | どの式で定義されたか |
| 変数の使用 | どのプロセスに渡されたか |
| 関数呼出 | どの関数にどの変数が渡され、結果がどの変数に入ったか |
| 戻り値 | returnされる変数 |

### クロスファイル
| 情報 | 内容 |
|------|------|
| 引数フロー | 関数A.変数x → 関数B.パラメータy |
| 戻り値フロー | 関数B.戻り値 → 関数A.結果変数 |

## 表示モード

### 関数内DFD
- 関数を選択 → その関数内の変数フローを表示
- ノード: 入力パラメータ、データストア(変数)、プロセス(関数呼出)、戻り値

### 概要DFD (フォルダモード)
- 各関数がプロセスノード
- 関数間のデータフローをエッジで表示

## GUI操作
- グラフ種別セレクタで「DFD」を選択
- 絞り込みバーで関数を選択 → その関数のDFDを表示
- ファイル切替に連動
- 全形式エクスポート対応
