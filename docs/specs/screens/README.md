# 画面設計書 一覧

全体アーキテクチャは [gui-app.md](../gui-app.md) を参照。

## 画面構成

```
MainWindow
├── ファイル一覧 (左, QSplitter可変, 折りたたみ可)
├── コード解析モード (Ctrl+1)
│   ├── ソースビューア (シンタックスハイライト + 行番号)
│   └── サブタブ: シンボル一覧 / トークン / AST
└── グラフ解析モード (Ctrl+2)
    ├── ツールバー (レイアウト / 表示モード / エクスポート19形式)
    ├── 絞り込み (ファイル → 関数 → 表示範囲)
    ├── グラフ種別セレクタ
    │   ├── コールツリー (列ベース階層 + L字接続線)
    │   ├── データフロー
    │   ├── フローチャート (JIS準拠図形)
    │   └── クラス図 (UML風ボックス)
    ├── グラフキャンバス
    └── 詳細パネル
```
