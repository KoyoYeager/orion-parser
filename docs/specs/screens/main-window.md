# 画面設計書: メインウィンドウ

## 画面概要

コード解析 / グラフ解析 の2モード構成。
ファイル/フォルダを開いて解析、結果を可視化する。

## レイアウト

```
メニューバー | ツールバー
[コード解析] [グラフ解析]  ← モードタブ
┌──────────┬──────────────────┐
│ ファイル   │ モードコンテンツ    │
│ 一覧      │                  │
│ (折畳可)  │                  │
└──────────┴──────────────────┘
ステータスバー
```

## ファイル一覧 (左サイドバー)
- フォルダ解析時のみ表示
- QSplitter で幅可変、折りたたみ可能
- ファイル選択 → コード解析ビュー + グラフのファイルフィルタが連動
- 解析状態アイコン (成功/失敗)

## 対応機能
- ファイル/フォルダ選択ダイアログ (Ctrl+O / Ctrl+Shift+O)
- ドラッグ&ドロップ
- テーマ切替 (ライト/ダーク)
- 文字コード自動判定 (chardet)
- ウェルカム画面 (起動直後)
- 最近開いたファイル
